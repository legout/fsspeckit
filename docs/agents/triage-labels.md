# Triage labels

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified for agent implementation |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Will not be actioned |

Labels indicate triage status; implementation still requires an approved behavioral source and execution authority.
